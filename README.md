# Valliente

Systems architect and software engineer specializing in high-performance computing, numerical simulations, native desktop applications, and real-time graphics engines.

---

### Core Focus Areas

- **Systems Architecture & Low-Level Engineering**: C++20, Rust, Python, Win32 APIs, WinDivert packet filter drivers, and standalone zero-dependency binary compilation.
- **Physics & Numerical Simulations**: Multi-stage orbital mechanics, 1976 US Standard Atmosphere, 2-DoF/6-DoF RK4 trajectory integrators, supersonic nozzle fluid dynamics, and biochemical reaction kinetics.
- **Desktop & Interactive Application Engines**: Qt 6 (C++ / QML / Qt Quick 3D), Tauri v2, Electron, React, WebGL, and WebAudio/WASM DSP pipelines.
- **Bioinformatics & Computational Biology**: Guide RNA candidate selection, CRISPR-Cas endonuclease mismatch scoring (Hsu-Zhang matrix), and microhomology-mediated end joining (MMEJ) repair prediction.
